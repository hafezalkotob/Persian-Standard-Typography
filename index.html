نمونه کامل پروس (Prose) – مقالهٔ جامع

عنوان اصلی: راهنمای طراحی تایپوگرافی فارسی در وب

تایپوگرافی یکی از مهم‌ترین عناصر طراحی واسط کاربری است. انتخاب درست فونت، وزن، هایلایت و پیوندها می‌تواند تجربهٔ خواندن را دگرگون کند. این یک متن کوچک توضیحی است که در کنار متن اصلی قرار می‌گیرد.

در ادامه به مفاهیمی مانند نقل‌قول درون‌خطی، فرمول‌های علمی (H2O یا x2)، ویرایش‌های متنی (حذف‌شده، اضافه‌شده، نامعتبر، زیرخط‌دار)، منابع (کتاب تایپوگرافی مدرن) و تعاریف (تایپوگرافی یعنی هنر چینش حروف) می‌پردازیم. همچنین کلیدهای میانبر مانند Ctrl + Z و کوته‌نوشت‌ها مانند CSS و تاریخ ۱۵ اردیبهشت ۱۴۰۵ نیز پوشش داده می‌شوند.

متن خنثی 123 و This text is left-to-right نیز گاهی در متون چندزبانه استفاده می‌شوند.

فصل اول: اهمیت تایپوگرافی

متن بخش بزرگی از رابط کاربری را تشکیل می‌دهد. یک پاراگراف خوب خوانایی را بالا می‌برد. همچنین line-height مناسب در body ضروری است.

زیرفصل: فاصلهٔ خطوط

فاصلهٔ خطوط (line-height) یکی از عوامل کلیدی خوانایی است. در زبان فارسی به دلیل حروف دندانه‌دار، فاصلهٔ بیشتر توصیه می‌شود.

Paragraph

تایپوگرافی در طراحی وب نقش بسیار مهمی در خوانایی و تجربه کاربری دارد. انتخاب فونت مناسب، فاصله خطوط، و اندازه متن می‌تواند تأثیر زیادی در درک محتوا داشته باشد.

یک سیستم تایپوگرافی استاندارد کمک می‌کند تا تمام صفحات وب‌سایت هماهنگ، منظم و حرفه‌ای دیده شوند.

Inline Elements

می‌توانید از متن بولد برای تأکید استفاده کنید، یا بخشی از متن را ایتالیک کنید. همچنین امکان هایلایت کردن بخش‌های مهم نیز وجود دارد.

برای نمایش کدهای کوتاه از display: flex یا npm install استفاده می‌شود.

این یک متن کوچک است که برای توضیحات جانبی، اعتبارسنجی یا نکات حقوقی به کار می‌رود.
