# تایپوگرافی استاندارد فارسی (PST)

یک سیستم تایپوگرافی تمیز، مدرن و کاملاً فارسی‌محور برای وب.  
PST شامل یک سیستم طراحی کامل، فونت‌های بهینه‌شدهٔ فارسی، توکن‌های آمادهٔ CSS، پشتیبانی از حالت تاریک، و یکپارچگی بی‌نقص با Elementor و WordPress است.

**[Read in English](README.md)**

---

## چرا PST؟

بیشتر فریم‌ورک‌های CSS فارسی را به‌عنوان یک موضوع فرعی در نظر می‌گیرند.  
PST **از پایه برای خط فارسی** ساخته شده است؛ با اندازهٔ فونت، ارتفاع خط، وزن، و فاصله‌گذاری‌هایی که متناسب با ویژگی‌های منحصربه‌فرد تایپوگرافی فارسی تنظیم شده‌اند.

- **فارسی‌محور:** تمام توکن‌ها و قواعد برای متن راست‌به‌چپ فارسی طراحی شده‌اند.
- **بدون letter-spacing:** برخلاف تایپوگرافی لاتین، `letter-spacing` معمولاً خوانایی فارسی را کاهش می‌دهد؛ در PST این مقدار صفر است.
- **بدون justify:** `text-align: justify` در متن فارسی فاصله‌های نامطلوب ایجاد می‌کند؛ PST از آن پرهیز می‌کند.
- **مجموعه‌فونت بهینه:** IranSansX، IranYekanX، Abar (Low/Mid/High)، و Vazirmatn همراه با تعریف صحیح `@font-face`.

## ویژگی‌ها

- 🎨 **توکن‌های طراحی** — رنگ‌ها، مقیاس تایپوگرافی، فاصله‌گذاری، و حالت تاریک
- 🔤 **۶ خانواده فونت فارسی** — بیش از ۶۰ وزن در ۴ تایپ‌فیس
- 🌙 **حالت تاریک** — تشخیص خودکار بر اساس سیستم‌عامل + کلید تغییر دستی
- 📐 **تایپوگرافی واکنش‌گرا** — مقیاس اندازه‌ها و فاصله‌ها برای موبایل
- 🧩 **یکپارچگی با Elementor** — فونت‌های PST مستقیماً در تنظیمات فونت Elementor نمایش داده می‌شوند
- 🧰 **افزونهٔ WordPress** — مدیریت فونت‌ها، CDN، و CSS سفارشی از یک پنل
- ⚡ **آماده برای CDN** — فایل‌های استاتیک بهینه برای تحویل سریع

## شروع سریع

### ۱) از طریق CDN

این خط را به بخش `<head>` صفحه اضافه کنید:
```html
<link rel="stylesheet" href="https://cdn.cdoc.ir/pst/css/main.css">
```

---

### ۲) از طریق افزونهٔ WordPress

1. پوشهٔ `pst-manager` را از مسیر `wordpress-plugin/` دریافت کنید.
2. آن را در `wp-content/plugins/` آپلود کنید.
3. افزونهٔ **PST Manager** را فعال کنید.
4. به **Settings → PST Manager** بروید.
5. فونت‌ها را انتخاب کنید، رنگ برند را تنظیم کنید، و ذخیره بزنید.

## ساختار پروژه

```
PST/
├── core/                   # هستهٔ سیستم طراحی (آماده برای CDN)
│   ├── css/
│   │   ├── base/           # ریست، توکن‌ها، تایپوگرافی، تنظیمات پایه
│   │   ├── components/     # فرم‌ها، جداول
│   │   └── main.css        # فایل ورودی اصلی
│   ├── fonts/              # فایل‌های فونت فارسی (woff/woff2)
│   ├── js/                 # تغییر تم، ابزارهای کمکی جدول
│   ├── img/                # تصاویر نمونه
│   └── index.html          # پیش‌نمایش تایپوگرافی
├── wordpress-plugin/       # افزونهٔ PST Manager برای WordPress
│   └── pst-manager/
└── README.md
```

## ساخت برای CDN

برای تولید نسخهٔ CDN با مسیرهای مطلق، اسکریپت build را اجرا کنید:

```bash
node build-cdn.js
```

خروجی در مسیر زیر ساخته می‌شود:

```text
core/dist/cdn/
```

این پوشه را روی CDN خود بارگذاری کنید.
