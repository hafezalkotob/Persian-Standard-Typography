# تایپوگرافی استاندارد فارسی (PST)

یک سیستم تایپوگرافی تمیز، مدرن و کاملاً فارسی‌محور برای وب.  
شامل یک سیستم طراحی کامل، فونت‌های بهینه‌شدهٔ فارسی، توکن‌های آمادهٔ CSS، پشتیبانی از حالت تاریک و یکپارچگی بی‌نقص با المنتور و وردپرس.

**[Read in English](README.md)**

## چرا PST؟

بیشتر فریم‌ورک‌های CSS، فارسی را به‌عنوان یک فکر ثانویه در نظر می‌گیرند. PST **از پایه برای خط فارسی** ساخته شده — با اندازه‌های فونت، فواصل خطوط، وزن‌ها و فاصله‌گذاری‌هایی که دقیقاً برای ویژگی‌های منحصربه‌فرد تایپوگرافی فارسی تنظیم شده‌اند.

- **فارسی‌محور**: هر توکن و قانون برای متن راست‌به‌چپ فارسی طراحی شده است.
- **بدون letter-spacing**: برخلاف تایپوگرافی لاتین، `letter-spacing` خوانایی فارسی را کاهش می‌دهد. ما آن را صفر نگه می‌داریم.
- **بدون Justification**: `text-align: justify` در فارسی فاصله‌های ناخوشایند ایجاد می‌کند. ما کاملاً از آن پرهیز می‌کنیم.
- **مجموعه فونت بهینه**: ایران‌سنس، ایران‌یکان، اَبَر (Low/Mid/High)، وزیرمتن — همگی با `font-face@` صحیح.

## ویژگی‌ها

- 🎨 **توکن‌های طراحی** — رنگ‌ها، مقیاس تایپوگرافی، فاصله‌ها و حالت تاریک
- 🔤 **۶ خانواده فونت فارسی** — بیش از ۶۰ وزن در ۴ تایپ‌فیس
- 🌙 **حالت تاریک** — تشخیص خودکار سیستم‌عامل + کلید دستی
- 📐 **تایپوگرافی واکنش‌گرا** — اندازه‌ها و فواصل در موبایل کوچک می‌شوند
- 🧩 **یکپارچگی با المنتور** — فونت‌های PST مستقیماً در لیست فونت المنتور ظاهر می‌شوند
- 🧰 **افزونهٔ وردپرس** — مدیریت فونت‌ها، CDN و CSS سفارشی از یک پنل ساده
- ⚡ **آماده برای CDN** — تمام دارایی‌های استاتیک برای تحویل از CDN بهینه شده‌اند

## شروع سریع

### از طریق CDN
این خط را به `<head>` پروژهٔ خود اضافه کنید:
```html
<link rel="stylesheet" href="https://cdn.cdoc.ir/pst/css/main.css">
```

### از طریق افزونهٔ وردپرس
1. پوشهٔ `pst-manager` را از مسیر `wordpress-plugin/` دانلود کنید.
2. آن را در `wp-content/plugins/` آپلود کنید.
3. افزونهٔ «PST Manager» را فعال کرده و به **تنظیمات → PST Manager** بروید.
4. فونت‌های مورد نظر را انتخاب کرده، رنگ‌های برند را تنظیم و ذخیره کنید.

│   ├── fonts/              ← فایل‌های فونت فارسی (woff/woff2)

│   └── index.html          ← پیش‌نمایش تایپوگرافی
├── wordpress-plugin/       ← افزونهٔ PST Manager برای وردپرس

## ساخت برای CDN

برای تولید فایل‌های آمادهٔ CDN با مسیرهای مطلق، اسکریپت build را اجرا کنید:

```bash
node build-cdn.js
```

خروجی در مسیر `core/dist/cdn/` قرار می‌گیرد. این پوشه را روی CDN خود آپلود کنید.
